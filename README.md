## ⟡ About

**CLOVER OOC** brings together ready-to-copy prompts, visual references, and mix-and-match builders for roleplay, character cards, and visual storytelling. Start with a complete scene, restyle an existing image, or combine character styling, poses, backgrounds, and effects into your own prompt.

The interface and entry titles support **English and Russian**. Copied prompts stay in English for consistent model instructions. Reference images illustrate results throughout the collections.

## ◇ Getting started

Browse a collection, copy a prompt, and use it with your image model or image-enabled roleplay chat. OOC prompts use `<ooc>…</ooc>` tags to mark an out-of-character instruction. Add styling details from the other libraries, or use Tools to assemble one combined block.

The [Guide](https://aceeenvw.github.io/clover-ooc/guide.html) explains syntax and how to combine prompts.
